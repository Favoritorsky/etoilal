# Etoilal — сайт языка

Статический сайт: самоучитель (35 уроков с озвучкой), экспресс-курс, словарь (≈8 800 слов), переводчик ⇄, «Проверь свой текст»,
справочник, карточки с интервальным повторением, тренировки, песни-караоке, библиотека, профиль и магазин.
Работает без сервера и без сборки: открой `index.html` (можно прямо с диска — через `file://`) или выложи папку на любой хостинг.

## Как опубликовать на GitHub Pages
1. Создай на GitHub пустой репозиторий (например, `etoilal`).
2. Загрузи в него **содержимое этой папки** (`site/`), чтобы `index.html` лежал в корне репозитория:
   ```
   cd ~/Красивый-язык/сайт/site
   git init && git add . && git commit -m "Сайт Etoilal"
   git branch -M main
   git remote add origin https://github.com/<твой-логин>/etoilal.git
   git push -u origin main
   ```
   Бэкапы `*.bak_*` в репозиторий не попадут (`.gitignore`).
3. На GitHub: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту сайт будет по адресу `https://<твой-логин>.github.io/etoilal/`.

Размер ≈ 50 МБ сейчас и ≈ 85 МБ после озвучки всего словаря (в основном `audio/`), это в пределах ограничений
GitHub Pages (сайт до 1 ГБ, файл до 100 МБ). После обновления файлов: `git add . && git commit -m "…" && git push`.

## Аккаунты (Supabase)
Без настройки всё работает: прогресс хранится в браузере (и его можно сохранить в файл в «Профиле»).
Чтобы заработали вход, прогресс на всех устройствах и топ недели:
1. В Supabase → SQL Editor выполни `../supabase.sql` (один раз; можно и повторно). Если ты уже выполнял старую версию —
   выполни только `../supabase_2_вход_по_нику.sql` (вход по нику: почта отдаётся сайту только при верном пароле,
   после 5 неудач за 15 минут вход по этому нику на 15 минут закрыт). Без этой функции вход работает по почте.
2. Supabase → Authentication → URL Configuration: Site URL = адрес сайта на GitHub Pages.
3. По желанию: Authentication → Providers → Email → «Confirm email» (с ним после регистрации приходит письмо).

На сайте хранится только публичный publishable key — секретные ключи никуда не вписывай.

## Как обновлять данные
Скрипты сборки — в `../tools/` (запуск из папки `сайт/`):
- `python3 tools/build_site_data.py` — словарь, фразы, данные переводчика;
- `~/.local/share/rivetfall-tts/venv311/bin/python tools/build_course.py` — уроки и их озвучка (`--no-tts` — без озвучки);
- `~/.local/share/rivetfall-tts/venv311/bin/python tools/build_words_audio.py` — озвучка слов словаря (продолжает с места остановки; `--dry` — сколько осталось);
- если видеокарта занята — на процессоре: `… venv311/bin/python tools/cpu_run.py tools/build_course.py`;
- переозвучить одну плохую фразу (много дублей, выбор по Whisper): `… venv311/bin/python tools/revoice.py "Фраза." --cpu`;
- проверка: `node tools/shots.cjs` (все страницы, ПК и телефон) и `node tools/test_*.cjs` / `test_*.mjs`.
